# 📁 Workshop_4_Simulation Folder

**IMPORTANT: This is a collection folder, NOT an execution environment**

This folder contains **a complete collection** of all the files used throughout the simulation project.  
Its purpose is to **document** and **organize** the project’s elements, **NOT to serve as a runnable environment**.

**If you want to run simulations or generate reports, DO NOT use this folder.**  
You must do so from the **original project folder**, where the files are placed in the correct structure to work properly.

---

## 📂 Folder Contents

### 1. `/results/`
This directory contains **all the results** obtained during the project, including:
- Numerical outputs  
- Plots and graphs  
- Processed reports  
- Any file generated by the simulations

> These results are for reference only.

---

### 2. `/Related Scripts/`
This folder contains all the simulation-related **`.py` scripts**

> Even though these scripts are the same as the ones in the project,  
**they will NOT work if executed from here**, since they depend on paths and resources that only exist in the original project structure.

---

### 3. `/Auto-Generated Report/`
This folder also includes the script for the **automatic report generator**, which:
- Analyzes the simulation results  
- Extracts conclusions  
- Builds a **PDF** report

**Warning:**  
⚠️ **The report generator will NOT work from this folder.**  
It depends on specific paths, dependencies, and files available only in the actual project directory. If you want to test it, put it on `FINAL_COURSE_PROYECT/generate_report.py` and run it.
